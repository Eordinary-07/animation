# 15 — Verified Page Images (Evidence Bundle)

Four of the eight source books exist only as image scans (Acting for Animators, The
Animator's Survival Kit, and figure-heavy pages of Stop Staring / Illusion of Life). The
decisive doctrine pages of those books are bundled here as JPEGs in `references/images/`
so the skill carries its own proof. **When a reference file cites one of these pages, the
image is the primary source — quote from the image, not from memory.**

How to use: open the image when you teach, rig, animate, or review anything based on that
page. If this skill's text and a bundled image ever disagree, the image wins.
