# AVA Voss — Shot Image Prompts (Storyboard Key Frames S01–S17)
### One frozen image per shot · for ChatGPT web app · animation pose/camera reference

Each prompt generates ONE still image = the exact key pose + exact camera of
that shot from `ava-voss-rig-test-production-script.md`. Generate all 17, name
them `S01.png … S17.png`, and use them in Blender as camera background images /
reference planes — pose Ava to match the image at that shot's key frame, and
your blocking stage is already directed.

**How to use:** one ChatGPT chat → paste **MESSAGE 0** first → then send the
shot prompts one by one (S01 → S17). Same chat = same character every time.

## 🔧 Correction cheat-sheet (reply in the same chat)

| Problem | Reply exactly this |
|---|---|
| Wrong side leading (mirrored) | "Mirror error. Regenerate: her LEFT side leads — left foot forward, left fist lead. When she faces camera her right side is on the LEFT of the frame." |
| Wrong limb doing the action | "Regenerate SHOT S0X: the [strike/block] is with her [RIGHT/LEFT] [arm/leg] exactly as written. Keep camera and everything else identical." |
| Color/textured skin or clothes | "Regenerate with <style_lock> exactly: untextured matte GREY CLAY everywhere, near-black void background, no color at all." |
| Limb cropped out of frame | "Regenerate with the ENTIRE body and extended limb inside the frame, margin on all sides." |
| Camera angle wrong | "Regenerate SHOT S0X with the camera exactly as specified: [height/angle/shot size from the prompt]. Same pose." |
| Ponytail missing/wrong | "Regenerate: single tight ponytail, darker grey clay, [position from the shot prompt]." |

## Using the images in Blender
Save as `S01.png … S17.png` → in each shot's camera: Camera Properties →
Background Images → add that shot's PNG (opacity ~0.5), or drop them as
reference Image Empties. Pose Ava at the shot's frozen frame (frame numbers
are in each prompt title) until her silhouette matches the image — that IS
your blocking pass, pre-directed.
